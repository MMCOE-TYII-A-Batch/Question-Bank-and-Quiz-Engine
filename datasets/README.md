# Question Bank Datasets

## Overview

This directory contains sample datasets used in the Question Bank & Quiz Generator project. These datasets are intended for database population, application testing, and frontend-backend integration.

---

## Files

| File | Description |
|------|-------------|
| `MCQ_QuestionBank.csv` | Sample dataset containing Multiple Choice Questions (MCQs). |
| `descriptivequestions.csv` | Sample dataset containing descriptive questions. |

---

## Dataset Usage

The datasets can be used to:

- Populate the question bank with sample data.
- Test database import and validation.
- Verify frontend and backend integration.
- Test quiz generation and question retrieval.

---

## File Format

The datasets are provided in **CSV (Comma Separated Values)** format and can be imported into the database or processed by the application.

---

## Notes

- The datasets are intended for testing and development purposes.
- Questions can be modified or extended as required.
